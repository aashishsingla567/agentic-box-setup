01
Install the OSYou · local console

Verify an official Mint, Ubuntu or Debian ISO; write USB; choose disk/encryption, user and boot network in the OS installer.

02
Choose the machine configurationYou · repo wizard

Clone the repo, select a profile or individual components, and inspect the read-only plan. OS selection validates compatibility; it does not install an OS.

03
Apply tools, runtime and storage checksRepo · selected scopes

Install CLIs/Node, create a fresh local proxy key, install the supported T3 service, and schedule storage checks. Cleanup starts disabled.

04
Authenticate this machineYou · supported account flows

Log in to providers/proxy, configure T3, enroll Tailscale or existing Headscale, add your client public key, and pair T3 Connect.

05
Opt into startup and operating policyRepo · after prerequisites

Enroll the home identity, stage boot SSH keys, enable the guarded workspace target, then choose power/resource policies. Persistent power is optional.

06
Prove remote readinessYou + local diagnostics

Save work, prove fallback access, reboot, test SSH before desktop login, unlock where needed, and open the authenticated T3 UI from your client.

Installed services are ready for onboarding. Usable accounts, remote pairing, verified backups and successful boot acceptance remain per-machine steps.
The login screen can stay displayed. Saved conversations/files persist; SSH sessions, builds and shell processes end at reboot. T3 continuation follows its own supported policy. A client must reconnect.

Home/user-manager checks: 15 seconds by default · functional health: 5 minutes · tailnet expiry below 24 hours produces a local warning. Remote authenticated UI verification is a separate client-side test.
